## 概述

zScript是zEngine框架中的脚本模块，用于实现行为树（Behavior Tree）逻辑。zScript支持通过GraphML文件可视化编辑行为树，并通过Python预转换为JSON格式，最终由Go运行时加载执行。

### 主要特性

- **可视化编辑** - 使用GraphML编辑器创建行为树
- **高性能加载** - 预转换为JSON格式，运行时加载速度快
- **动态函数注册** - 支持自定义脚本函数
- **表达式解析** - 支持复杂的条件表达式
- **类型安全** - 支持多种数据类型和运算符
- **模块化设计** - 可与zEngine其他模块无缝集成

### 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                       开发阶段                                 │
├─────────────────────────────────────────────────────────────┤
│  GraphML编辑器 → 行为树设计 → Python转换脚本 → JSON文件         │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│                       运行时阶段                                 │
├─────────────────────────────────────────────────────────────┤
│  Go程序 → 加载JSON → 解析AST → 执行逻辑 → 函数调用            │
└─────────────────────────────────────────────────────────────┘
```

## 快速开始

### 环境要求

- Python 3.6+ (用于转换GraphML文件)
- Go 1.21+ (用于运行时)
- GraphML编辑器 (推荐: yEd Graph Editor)

### 1分钟快速上手

#### 步骤1: 创建GraphML文件

使用GraphML编辑器创建行为树，保存为`test.graphml`。

#### 步骤2: 转换为JSON

```bash
python convert_graphml_to_json.py test.graphml
```

生成`test.json`文件。

#### 步骤3: 编写Go代码

```go
package main

import (
    "github.com/pzqf/zEngine/zScript"
)

func main() {
    // 加载脚本
    err := zScript.LoadScriptFile("test.json")
    if err != nil {
        panic(err)
    }

    // 注册脚本函数
    zScript.RegisterScriptFunc(MoveToTarget)
    zScript.RegisterScriptFunc(IsMoveInControl)

    // 绑定脚本
    holder := zScript.ScriptHolder{}
    err = holder.BindScript("test.json")
    if err != nil {
        panic(err)
    }

    // 执行脚本
    for i := 0; i < 10; i++ {
        holder.Update(16)
    }
}

func MoveToTarget(holder *zScript.ScriptHolder, args ...interface{}) interface{} {
    // 实现逻辑
    return nil
}

func IsMoveInControl(holder *zScript.ScriptHolder, args ...interface{}) interface{} {
    return true
}
```

## 工作流程

### 完整工作流程

```
1. 设计行为树 (GraphML编辑器)
   ↓
2. 转换为JSON (Python脚本)
   ↓
3. 注册自定义函数 (Go代码)
   ↓
4. 加载脚本 (LoadScriptFile)
   ↓
5. 绑定脚本 (BindScript)
   ↓
6. 执行脚本 (Update)
```

### 详细说明

#### 阶段1: 开发阶段

1. **设计行为树**
   - 使用GraphML编辑器创建节点和边
   - 节点内容: 脚本函数调用
   - 边内容: 条件表达式

2. **转换为JSON**
   - 运行Python转换脚本
   - 只保留必要的数据
   - 生成压缩的JSON格式

#### 阶段2: 运行时阶段

1. **注册自定义函数**
   - 使用RegisterScriptFunc注册回调函数
   - 函数签名: `func(*ScriptHolder, ...interface{}) interface{}`

2. **加载脚本**
   - 调用LoadScriptFile加载JSON文件
   - 解析节点和边数据
   - 生成AST语句

3. **绑定脚本**
   - 创建ScriptHolder实例
   - 调用BindScript绑定脚本文件
   - 验证脚本结构

4. **执行脚本**
   - 调用Update执行脚本逻辑
   - 根据条件选择下一个节点
   - 执行节点的脚本函数

## GraphML编辑器指南

### 推荐工具

- **yEd Graph Editor** (免费, 推荐)
  - 下载: https://www.yworks.com/products/yed
  - 支持Windows, macOS, Linux
  - 支持GraphML格式

- **其他工具**
  - draw.io (在线, 免费)
  - Lucidchart (商业)
  - Mermaid (Markdown)

### 节点类型

#### 1. 入口节点 (Entry Node)

- **ID**: n1 (示例)
- **内容**: Entry
- **功能**: 行为树的起始节点
- **外观**: 橙色矩形

#### 2. 退出节点 (Exit Node)

- **ID**: n0 (示例)
- **内容**: Exit
- **功能**: 行为树的结束节点
- **外观**: 橙色矩形

#### 3. 动作节点 (Action Node)

- **ID**: 自定义 (如n2, n3等)
- **内容**: 函数调用 (如MoveToTarget(1))
- **功能**: 执行特定的动作
- **外观**: 橙色矩形

### 边类型

#### 1. 条件边 (Condition Edge)

- **ID**: 自定义 (如e0, e1等)
- **Source**: 源节点ID
- **Target**: 目标节点ID
- **内容**: 条件表达式 (如IsMoveInControl())
- **功能**: 根据条件跳转到目标节点

#### 2. 默认边 (Default Edge)

- **内容**: 空字符串或不填写
- **功能**: 无条件跳转到目标节点

### 编辑示例

#### 创建Entry节点

1. 拖放一个矩形节点到画布
2. 设置标签为 "Entry"
3. 设置颜色为橙色
4. 复制节点ID (如n1)

```xml
<node id="n1">
  <data key="d5">
    <y:ShapeNode>
      <y:NodeLabel>Entry</y:NodeLabel>
      <y:Fill color="#FFCC00"/>
    </y:ShapeNode>
  </data>
</node>
```

#### 创建Action节点

1. 拖放一个矩形节点到画布
2. 设置标签为 "MoveToTarget(1)"
3. 设置颜色为橙色
4. 复制节点ID (如n2)

```xml
<node id="n2">
  <data key="d5">
    <y:ShapeNode>
      <y:NodeLabel>MoveToTarget(1)</y:NodeLabel>
      <y:Fill color="#FFCC00"/>
    </y:ShapeNode>
  </data>
</node>
```

#### 创建Condition Edge

1. 从源节点拖到目标节点
2. 设置标签为 "IsMoveInControl()"
3. 设置箭头样式

```xml
<edge id="e0" source="n1" target="n2">
  <data key="d9">
    <y:PolyLineEdge>
      <y:EdgeLabel>IsMoveInControl()</y:EdgeLabel>
      <y:Arrows target="standard"/>
    </y:PolyLineEdge>
  </data>
</edge>
```

### 命令行使用

#### 单个文件转换

```bash
python convert_graphml_to_json.py input.graphml
```

输出: `input.json`

#### 指定输出文件

```bash
python convert_graphml_to_json.py input.graphml -o output.json
```

#### 批量转换目录

```bash
python convert_graphml_to_json.py ./graphs -o ./scripts
```

将 `./graphs` 目录下所有 `.graphml` 文件转换为 `.json` 文件，保存到 `./scripts` 目录。

```json
{
  "nodes": [
    {
      "id": "n0",
      "content": "Exit"
    },
    {
      "id": "n1",
      "content": "Entry"
    },
    {
      "id": "n2",
      "content": "MoveToTarget(1)"
    }

  "edges": [
    {
      "id": "e0",
      "source": "n1",
      "target": "n2",
      "content": "IsMoveInControl()"

```

## Go API参考

### 核心类型

#### ScriptData

```go
type ScriptData struct {
    Nodes [][Node `json:"nodes"`]
    Edges [][Edge `json:"edges"`]
}
```

行为树的完整数据结构。

#### Node

```go
type Node struct {
    Id      string        `json:"id"`
    Content string        `json:"content"`
    Stmt    *ast.ExprStmt // 解析后的AST语句
    Edges   []Edge        `json:"edges"`
}
```

行为树节点，包含节点ID、内容和输出边。

#### Edge

```go
type Edge struct {
    Id      string        `json:"id"`
    Content string        `json:"content"`
    Stmt    *ast.ExprStmt // 解析后的AST语句
    Target  string        `json:"target"`
    Source  string        `json:"source"`
}
```

行为树边，包含源节点、目标节点和条件表达式。

#### ScriptHolder

```go
type ScriptHolder struct {
    script           *ScriptData    // 脚本数据
    currScriptNodeId string         // 当前节点ID
}
```

脚本执行器，用于管理和执行行为树。

#### ScriptFunc

```go
type ScriptFunc func(holder *ScriptHolder, args ...interface{}) interface{}
```

脚本函数签名，自定义函数必须遵循此签名。



**参数:**
- `deltaTime` - 时间增量（毫秒）

**示例:**

### 事件驱动脚本

#### 监听节点变化

```go
type ScriptObserver struct {
    onNodeChange func(from, to string)
}

func (ob *ScriptObserver) Attach(holder *zScript.ScriptHolder) {
    // 拦截Update方法
    originalUpdate := holder.Update
    
    holder.Update = func(deltaTime int) {
        currentNode := holder.currScriptNodeId
        originalUpdate(deltaTime)
        newNode := holder.currScriptNodeId
        
        if currentNode != newNode {
            ob.onNodeChange(currentNode, newNode)
        }
    }
}
```

#### 实现状态机

```go
type StateMachine struct {
    states map[string]*ScriptHolder
    currentState string
}

func (sm *StateMachine) ChangeState(state string) {
    sm.currentState = state
    sm.states[state].ResetScript()
}

func (sm *StateMachine) Update(deltaTime int) {
    sm.states[sm.currentState].Update(deltaTime)
}
```

```go
    // 设置zScript的日志器
    zScript.SetLogger(logger)

    if err != nil {
        panic(err)
    }
}
```

## 故障排除

### 常见错误及解决方案

#### 1. 加载失败

```
Failed to load script: open test.json: no such file or directory
```

**原因:** JSON文件不存在

**解决方案:**
1. 确保已运行Python转换脚本
2. 检查文件路径是否正确
3. 确认文件扩展名是.json而非.graphml

```bash
python convert_graphml_to_json.py test.graphml
```

#### 2. 绑定失败

```
the script test.json no entry node
```

**原因:** JSON文件中没有Entry节点

**解决方案:**
1. 检查GraphML文件中是否有Entry节点
2. 确保Entry节点的内容是"Entry"
3. 重新转换JSON文件

#### 3. 函数未找到

```
Can't find function [MoveToTarget]
```

**原因:** 自定义函数未注册或函数名不匹配

**解决方案:**
1. 确保调用了RegisterScriptFunc
2. 检查函数名大小写是否匹配
3. 确认函数参数和返回值类型正确

```go
RegisterScriptFunc(MoveToTarget)  // 正确
RegisterScriptFunc(movetotarget)  // 错误，大小写不匹配
```

#### 4. 运行时Panic

```
runtime error: invalid memory address or nil pointer dereference
```

**原因:** 访问nil指针的字段

**解决方案:**
1. 确保在使用指针前检查是否为nil
2. 在自定义函数中添加参数验证

```go
targetNode := sh.getNodeById(newNodeId)
if targetNode != nil {
    fmt.Println("-->to node:", newNodeId, ", exec:", targetNode.Content)
}
```

#### 5. 表达式解析失败

```
Parse error: expected ')', found ','
```

**原因:** 表达式语法错误

**解决方案:**
1. 检查函数调用的括号是否匹配
2. 确认参数数量和类型正确

```
MoveToTarget(1, 2, 3)  // 正确
MoveToTarget(1, 2,      // 错误，缺少右括号
```

#### 6. 类型不匹配

```
invalid operation: x || y (mismatched types int and bool)
```

**原因:** 运算符应用于不兼容的类型

**解决方案:**
1. 检查表达式中操作数的类型
2. 使用类型转换确保类型匹配

```go
// 错误
IsAttackInRange() + 1  // bool + int

// 正确
int(IsAttackInRange()) + 1  // bool -> int
```

#### 7. Python转换失败

```
UnicodeDecodeError: 'gbk' codec can't decode byte 0x93
```

**原因:** Python脚本的编码问题

**解决方案:**
1. 确保使用UTF-8编码
2. 检查GraphML文件的编码

```bash
python convert_graphml_to_json.py input.graphml
```

### 1. 行为树设计准则

#### 保持树的简洁

- 每个节点只做一件事
- 避免过深的嵌套

#### 使用标准节点类型

- **Entry** - 树的入口
- **Exit** - 树的出口
- **Action** - 执行动作
- **Condition** - 条件判断

#### 优化条件路径

- 最常用的条件放在前面
- 避免在条件中执行复杂计算
- 使用缓存或预计算结果

### 2. 函数设计准则

#### 单一职责原则

```go
// 好的设计
func MoveToTarget(holder *ScriptHolder, args ...interface{}) interface{} {
    // 只负责移动到目标
    targetX := args[0].(float64)
    targetY := args[1].(float64)
    MoveTo(holder, targetX, targetY)
    return nil
}

func IsAttackInRange(holder *ScriptHolder, args ...interface{}) interface{} {
    // 只负责检查攻击范围
    return GetDistance(holder) < GetAttackRange(holder)
}

// 差的设计
func MoveAndAttack(holder *ScriptHolder, args ...interface{}) interface{} {
    // 职责过多
    targetX := args[0].(float64)
    targetY := args[1].(float64)
    MoveTo(holder, targetX, targetY)
    
    if GetDistance(holder) < GetAttackRange(holder) {
        Attack(holder)
    }
    
    return nil
}
```
